THE WHITELIST

98 characters. Printable ASCII (U+0020 through U+007E) plus tab (U+0009), newline (U+000A), and carriage return (U+000D). Everything outside this set is decoded, classified by placement and historical layer, and either converted to an ASCII equivalent or stripped.

INTEGRATED ENIGMA & SUBSTRATE TDR MODULES

1. Enigma DecodeAttempts 4 steganography decoders on hidden runs: Tag-Block ASCII (U+E0000), Variation Selector nibble/byte indexing, Zero-Width Binary (5 polarity pairs), and Zero-Width Base-3 Ternary.
2. JSON Escape UnpackerDetects hidden characters smuggled inside ASCII-legal \uXXXX and surrogate-pair JSON escape strings before scanning.
3. Placement & IntentClassifies every hidden character as SEMANTIC (deliberate mid-word or identity-adjacent) vs STRUCTURAL (formatting boundary) and separates benign VS16 emoji plumbing from real signal.
4. File Disguise CheckInspects raw file head magic bytes against declared extensions to catch HTML, SVG, shell scripts, or JSON masquerading as images or binaries.
5. DOM Blind-Spot AuditParses HTML source to expose JSON-LD blocks stripped by live AI fetchers, image alt attributes truncated around 75-80 characters by browsing sanitizers, and hidden CSS/DOM prompt-injection vectors.
6. SHA-256 ProvenanceGenerates a deterministic SHA-256 hash and timestamped Ground-Truth Manifest of the sanitized 98-character carrier text.
